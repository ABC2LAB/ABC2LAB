Web 응답 확인 중

기존 Runner를 Development 단일 회차로 실행하고 공개 산출물을 표시한다. 평가 지표는 후속 단계다. Web 정상 응답은 대상 접속이나 모델 준비 완료를 뜻하지 않는다.

새 진단

준비한 Collector 설정에 입력을 연결한다. 입력 준비는 진단 시작이나 로그인 성공을 의미하지 않는다.

진단 입력

http(s) URL을 입력한다. URL 안의 인증정보·query·fragment는 받지 않는다. 실제 요청 허용 범위는 Collector와 Safety Policy가 검사한다.

읽기 전용 datasets 경로의 목록이다. Web은 Ground Truth 내용을 읽지 않는다.

테스트 계정

같은 역할의 계정을 여러 개 추가할 수 있다. 역할·별칭은 소문자·숫자·밑줄로 입력한다. 별칭은 공개 결과에 나가므로 로그인 ID와 다르게 지정한다. 익명 guest는 Collector가 자동으로 추가한다.

로그인 ID·비밀번호는 준비 요청 후 입력칸에서 지운다. 서버 메모리에만 일시 보관하며 브라우저 저장소나 설정 파일에는 저장하지 않는다.

Knowledge Graph

검증 전 query 시점의 실제 structure_snapshot이다. 검증 반영 후 최신 그래프가 아니다. 속성 원문 대신 공개 node_id·종류·basis·Resource 범위를 표시한다.

진단 과정

ID로 후보·시나리오·정책·검증을 연결한다. 후보나 verifier의 success를 Web이 확정 취약점으로 바꾸지 않는다.

결과 리포트 · 확인된 취약점

Reporter가 confirmed로 분류한 항목만 아래 목록에 표시한다. 0건은 웹 전체에 취약점이 없다는 뜻이 아니다.

승인 대기

Safety Policy의 require_approval 항목만 표시한다. 이 MVP에서는 승인·정책 수정·재개를 제공하지 않는다.
