입력·실행 경계 안내

역할·공개 별칭은 소문자·숫자·밑줄을 사용한다. 비밀값은 서버 메모리에 일시 보관하며 공개 결과·설정 파일에 저장하지 않는다.

기존 Runner의 Development 단일 회차를 실행한다. Web 상태·입력 준비는 대상 로그인이나 실제 모델 연결 성공을 뜻하지 않는다. Ground Truth 원문은 Reporter만 평가에 사용한다.
